# Adelaide House Prices
Consists of a Jupyter notebook, a Javascript file, and an HTML file.
The Jupyter notebook:
1. Fetches metro median Adelaide house sales data from data.sa.gov.au
2. Fetches Adelaide Suburb geographical data from data.sa.gov.au
3. Cleans, consolidates, and joins the data.
4. (Optional) generates an internal map visualisation within the notebook environment.
5. (Optional) generates data files for use by the Javascript and HTML file.
