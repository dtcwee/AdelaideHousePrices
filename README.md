# Adelaide House Prices

Map house prices and sales over time for suburbs in metropolitan Adelaide, South Australia.

## Contents
1. Jupyter Notebook, hosted on [Google Colab](https://colab.research.google.com/drive/1zxywnW1_DflwM2TZp5CvwFk4_iidink2?usp=sharing).
2. Data File `adelaide_property_data.geojson.gz` generated by the notebook.
2. HTML/JS Suite for processing and visualising the datafile on a web browser.

# Notes

## The Jupyter notebook:
1. Fetches suburb and sales data from the [South Australian Government](https://data.sa.gov.au) 
2. Cleans, consolidates, and joins the data.
3. (Optional) generates an internal map visualisation within the notebook environment.
4. (Optional) generates a compressed GeoJSON file for use by the HTML/JS Suite.

## Data
There is no sales volume data until 2022.
