# Adelaide House Prices

Visualise house prices and sales over time for suburbs in metropolitan Adelaide, South Australia.

Try the [Interactive Map](https://dtcwee.github.io/ADLHousePrices/).

Generate fresh data on [Google Colab](https://colab.research.google.com/drive/1zxywnW1_DflwM2TZp5CvwFk4_iidink2?usp=sharing).

## Components
1. Jupyter Notebook, hosted on Colab. 
2. Compressed GeoJSON data file `adelaide_property_data.geojson.gz` generated by the notebook.
2. HTML/JS Suite for processing and visualising the datafile on a web browser.

# How it Works

## Jupyter Notebook
1. Fetches official [South Australian Government](https://data.sa.gov.au) suburb boundary and sales data.  
2. Cleans, consolidates, and joins the data.
3. *(Optional)* generates an internal map visualisation within the notebook environment.
4. *(Optional)* generates `adelaide_property_data.geojson.gz` for use by the HTML/JS Suite.

## HTML/JS/CSS Suite
1. Uncompresses `adelaide_property_data.geojson.gz` and loads GeoJSON.
2. Generates web visualisation.

## Data Notes
1. There is no sales volume data until 2022.
2. Not all suburbs have consistent data points.
3. Data © South Australian Government.
